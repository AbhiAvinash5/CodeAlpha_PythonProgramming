##  About the Project

CodeBot is a friendly rule-based chatbot that understands common conversational inputs and responds intelligently. It features multiple random replies per intent (so it never sounds repetitive), a simulated typing effect, real-time clock support, and graceful error handling.


##  Features

-  Understands 11 different intents (greetings, jokes, time, goodbye, etc.)
-  Multiple random replies per intent — never sounds repetitive
-  Real-time current time using `time.strftime()`
-  Simulated typing delay for a natural chat feel
-  Handles empty input and `Ctrl+C` gracefully
-  Shows conversation turn count on exit





##  How to Run

### Prerequisites
- Python 3.x installed (no external libraries needed)


# Clone the repository
git clone https://github.com/YOUR_USERNAME/CodeAlpha_PythonProgramming.git

# Navigate to the folder
cd CodeAlpha_PythonProgramming

# Run the chatbot
python chatbot.py
