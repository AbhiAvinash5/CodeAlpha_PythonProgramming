# Email Extractor — CodeAlpha Task 3

A Python automation script that extracts all valid email addresses from a `.txt` file and saves them to an output file. Built as part of the CodeAlpha Python Programming Internship.

---

##  About the Project

This script automates the tedious task of manually finding email addresses in large text files. Using Regular Expressions (Regex), it scans any `.txt` file, pulls out all valid emails, removes duplicates, and saves a clean list to a new file — in seconds.



##  Features

-  Regex-powered email detection — finds all valid email formats
-  Automatically removes duplicate emails using Python `set()`
-  Built-in sample file generator for instant testing
-  File existence check before processing
-  Saves results to a clean `.txt` output file
-  Displays results as a numbered list in the console



##  How to Run

- Python 3.x installed (no external libraries needed)
